# Microchallenge 4.A — «Está cifrado, ¿está protegido?»

**Duración:** 15 minutos  
**Modalidad:** parejas o grupos de 3

## Objetivo

Separar correctamente los conceptos de **cifrado, confidencialidad, integridad, autorización, custodia de claves y observabilidad**.

## Casos

Analiza las siguientes afirmaciones:

**A.** “La base de datos está cifrada con AES-256; por tanto, una cuenta DBA comprometida no supone riesgo de confidencialidad.”

**B.** “El API utiliza HTTPS; por tanto, no necesitamos revisar autorización a nivel de objeto.”

**C.** “Las claves están almacenadas en un HSM; por tanto, no necesitamos logging de operaciones criptográficas.”

**D.** “Los backups están cifrados; la clave de descifrado forma parte del mismo procedimiento de recuperación y se guarda junto con la documentación operativa.”

**E.** “El fichero se clasifica como PUBLIC, por lo que su integridad no necesita controles adicionales.”

Selecciona el caso que consideres **más peligroso para una organización telco** y defiende tu elección.

No existe una única respuesta correcta si la justificación es técnicamente sólida.
