# Programa Avanzado de Ciberinteligencia y Ciberdefensa

Material para alumnos del **Programa Avanzado de Ciberinteligencia y Ciberdefensa**.

El repositorio se publica de forma progresiva: las presentaciones y los enunciados de laboratorio se irán incorporando a medida que avance el programa.

## Estructura

```text
modulo-01/
├── presentacion/
└── laboratorios/

modulo-02/
├── presentacion/
└── laboratorios/
```

Cada módulo contiene únicamente el material destinado al alumno. Las guías de instructor, soluciones y materiales internos no forman parte de este repositorio.

## Contenido disponible

### Módulo 1 — Fundamentos de Ciberseguridad, Ciberinteligencia y Ciberdefensa
- Presentación del módulo.
- Enunciados de laboratorio.

### Módulo 2 — Dirección y Gobernanza de la Ciberseguridad
- Presentación del módulo.
- Enunciados de laboratorio.

## Uso del material

Los ejercicios técnicos deben realizarse exclusivamente dentro del **Telvora Cyber Range** y de los entornos expresamente autorizados para el curso.

> El contenido del repositorio irá creciendo durante el programa. Que un módulo todavía no aparezca no significa que no forme parte del temario.
