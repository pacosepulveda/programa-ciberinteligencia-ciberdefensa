# MA06.B — Pistas progresivas

1. ¿Qué elementos visibles permiten acotar el tipo de infraestructura? Evita depender solo de la descripción de la publicación.
2. Los créditos obligatorios de licencia y las URLs técnicas de las imágenes pueden ser pistas, pero **no prueban el lugar, la fecha ni el incidente**.
3. Busca fuentes públicas históricas, ficha de archivo, fecha de subida y fecha EXIF si existe.
4. La MediaWiki API admite nombres de fichero con prefijo File: y devuelve propiedades imageinfo.
5. Compara las dos fotografías y decide si realmente muestran la misma estructura.
6. En GEOINT, una ubicación de la **cámara** no es necesariamente la ubicación del **objetivo fotografiado**.
7. Un mensaje que enlaza dos publicaciones anteriores no crea una tercera fuente independiente.
8. ¿Una fotografía de una torre demuestra por sí sola un fallo, una reparación o un ciberataque? ¿Qué otra evidencia haría falta?
