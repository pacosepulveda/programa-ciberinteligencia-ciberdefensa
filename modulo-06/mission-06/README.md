## Alcance

Los materiales y datos operativos de TELVORA son ficticios. Las direcciones de ejemplo están reservadas para documentación. El advisory de CISA utilizado como fuente de contexto describe hechos reales y no atribuye actividad a la TELVORA ficticia.

No se permite escanear terceros, contactar con supuestos objetivos, interactuar con indicadores de compromiso ni utilizar datos privados de personas ajenas al ejercicio.
