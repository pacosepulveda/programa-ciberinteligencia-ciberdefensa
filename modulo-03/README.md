## Recorrido práctico

```text
Microchallenge 3.A
      ↓
intención y trust assumptions
      ↓
P03.0 · microsegmentación + management plane + evidencia
      ↓
P03.1 · segmentación por intención con firewall
      ↓

      ↓
P03.3 · arquitectura cloud + IaC + policy-as-code
      ↓
Mission 03 · Architecture Defence Pack
```

Las prácticas utilizan el **Telvora Cyber Range** y están diseñadas para validar la arquitectura mediante evidencia técnica, no solo mediante diagramas o decisiones de configuración.
